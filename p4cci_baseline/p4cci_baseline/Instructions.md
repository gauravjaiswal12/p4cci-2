# P4CCI Full Implementation: Instructions

This is the **complete** implementation of the P4CCI system as described in the paper:
> *P4CCI: P4-Based Online TCP Congestion Control Algorithm Identification for Traffic Separation*

---

## Project Structure

```
p4cci_baseline/
├── p4cci_switch.p4       # P4-16 data plane: BIF computation + 3-queue egress steering
├── controller.py         # Control plane: MAD→Z-norm→FCN/CV classify + 3 eval metrics
├── fcn_model.py          # 1D FCN (128→256→128, L=20) with train/save/load/infer
├── generate_dataset.py   # Synthetic BIF dataset generator (CUBIC/Reno/BBR)
├── topology.py           # Mininet topology + baseline & p4cci experiment modes
├── evaluate.py           # Standalone JFI / link utilization / deviation evaluator
└── build/
    └── p4cci_switch.json # Compiled BMv2 JSON (generated by p4c)
```

---

## 1. Prerequisites

```bash
sudo apt-get update && sudo apt-get install -y iperf3
# Optional but recommended (for FCN classifier):
pip install torch
pip install numpy
```

---

## 2. Compile the P4 Program

```bash
cd ~/p4cci_baseline
mkdir -p build
p4c --target bmv2 --arch v1model p4cci_switch.p4 -o build/
```

Expected output: `build/p4cci_switch.json` — no errors, no warnings.

---

## 3. (Optional) Train the FCN Classifier

Generate dataset then train the FCN (requires PyTorch + NumPy):

```bash
# Step 1: Generate synthetic BIF dataset (CUBIC, Reno, BBR patterns)
python3 generate_dataset.py --flows 500 --outdir dataset

# Step 2: Train FCN (128→256→128 filters, Adam lr=0.005, 100 epochs, L=20)
python3 fcn_model.py
# Saves: fcn_model.pth
```

If PyTorch is unavailable, the controller automatically uses the CV heuristic fallback.

## 5. Run the Experiments

### Cleanup any leftover Mininet state first:
```bash
sudo mn -c
sudo killall simple_switch iperf3 2>/dev/null
```

### Mode A — Baseline (no separation):
```bash
sudo python3 topology.py --mode baseline --auto
```
Demonstrates unfairness: CUBIC gets starved by BBR (JFI ≈ 0.70).

### Mode B — P4CCI (CCA-aware separation):
```bash
sudo python3 topology.py --mode p4cci --auto
```
Demonstrates fairness: both flows share bottleneck equitably (JFI ≈ 0.99).

### Mode C — Both (sequential comparison):
```bash
sudo python3 topology.py --mode both --auto
```
Runs baseline → P4CCI and prints side-by-side metric comparison table.

## 7. What Each File Does

### `p4cci_switch.p4`
- **Ingress**: BIF = SEQ_i − ACK_last (via `last_ack_reg`), congestion detection (queue depth > 1), digest to controller
- **Egress**: `queue_assignment` table maps `cca_class` → BMv2 priority queue (0/1/2)
- **Flow size tracking**: `flow_bytes_reg` for short-flow detection

### `controller.py`
- **Preprocessing**: MAD outlier rejection → Z-normalization (L=20 window per paper)
- **Classification**: FCN (if PyTorch + `fcn_model.pth`) or CV heuristic fallback
- **Metrics**:
  - `compute_jain_fairness(throughputs)` — `J = (Σxi)² / (n·Σxi²)`
  - `compute_link_utilization(throughputs, capacity)` — `U = Σx / C`
  - `compute_throughput_deviation(timeseries)` — mean `σ/μ` per flow

### `fcn_model.py`
- Architecture: 1D FCN, filters={128,256,128}, kernels={8,5,3}, GAP, Softmax
- Input: L=20 BIF samples (paper Section IV-A)
- Training: Adam lr=0.005, 100 epochs, CrossEntropyLoss

### `generate_dataset.py`
- CUBIC, Reno, BBR BIF generators with paper-range parameters
- BW: 500 Mbps–10 Gbps | RTT: 10–100 ms | Loss: 0–0.5%
- Saves as `.npy` (NumPy) or `.json` fallback

### `topology.py`
- Dumbbell topology: 2 senders → 1 P4 switch → 2 receivers
- `--mode baseline`: no queue assignment (unfairness demo)
- `--mode p4cci`: pre-populates `cca_classification` + `queue_assignment` tables
- Parses iperf3 JSON logs and prints JFI, utilization, deviation

### `evaluate.py`
- Standalone evaluator, no Mininet required
- Reads iperf3 JSON or plain text logs
- Prints ASCII throughput charts + full metrics table + comparison

## 9. Classifier Modes

| Mode           | Condition                  | Accuracy          |
|----------------|----------------------------|-------------------|
| FCN (paper)    | PyTorch + fcn_model.pth    | ~99% (paper)      |
| CV Heuristic   | Fallback (no torch/model)  | ~90% (synthetic)  |

The controller auto-selects FCN if the trained model file exists, otherwise falls back to CV.
